# The Gentle Word Co.

A peaceful static website for Christian women overcoming perfectionism, built with lightweight HTML, CSS, and minimal JavaScript. No frameworks. No WordPress. Just clean, fast, accessible pages.

## Tech Stack

- **HTML/CSS** — Hand-written, no frameworks
- **JavaScript** — Minimal vanilla JS for mobile nav and form handling
- **Node.js build script** — Converts Markdown blog posts to HTML, generates RSS, sitemap, robots.txt
- **Cloudflare Pages** — Hosting via GitHub Git integration

## Routes

The build script outputs directory-based routes (no `.html` in URLs):

| Route | Source |
|---|---|
| `/` | `pages/index.html` |
| `/gentle-reset-starter-kit/` | `pages/starter-kit.html` |
| `/blog/` | Generated by build script |
| `/blog/archive/` | Generated by build script |
| `/blog/{slug}/` | Generated from `posts/{slug}.md` |
| `/blog/rss.xml` | Generated RSS feed |
| `/sitemap.xml` | Generated sitemap |
| `/robots.txt` | Generated robots.txt |

## Build & Preview

```bash
npm install      # Install dependencies (gray-matter, marked)
npm run build    # Build site to _site/
npm run preview  # Serve _site/ locally at http://localhost:8080
```

For development with auto-rebuild:
```bash
npm run dev      # Build + serve locally at http://localhost:8080
```

## Blog Post Format

Create a Markdown file in `posts/` with this frontmatter:

```yaml
---
title: "When Rest Feels Like Laziness"
excerpt: "Learning to receive God's invitation to stillness without guilt."
publishDate: 2025-07-15
author: Jessica
category: Rest
tags: [rest, perfectionism, grace]
image: /assets/images/blog/when-rest-feels-like-laziness.jpg
---

Your Markdown content here...
```

**Future publish dates:** Posts with a `publishDate` in the future are automatically excluded from the build. They appear on the live site only after their date arrives.

## Deployment

### Cloudflare Pages Git Integration (Primary)

1. Connect this repository to Cloudflare Pages
2. Set build command: `npm run build`
3. Set output directory: `_site`
4. Set production branch: `main`

Cloudflare will automatically rebuild and deploy whenever commits are pushed to `main`.

### Scheduled Publishing (GitHub Actions)

`.github/workflows/publish.yml` runs once daily (Mon–Sat, skip Sundays) at 07:00 UTC. It checks if any blog post has a `publishDate` equal to today. If so, it makes an empty commit to trigger a Cloudflare rebuild. If no posts are newly eligible, it does nothing.

This workflow does NOT deploy anything. It does NOT require a Cloudflare API token. It only triggers a rebuild via Git push.

If you prefer manual control, disable the workflow and push a commit manually when a post goes live.
